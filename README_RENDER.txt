VYAPAAR SATHI — RENDER DEPLOYMENT

1) Create/sign in to a Render account.
2) Create a new Web Service and upload/connect this project folder/repository.
3) Render will use:
   Build: pip install -r requirements.txt
   Start: gunicorn app:app --bind 0.0.0.0:$PORT --workers 1 --threads 4 --timeout 120
4) In Environment Variables add:
   GEMINI_API_KEY = your Gemini API key
5) Deploy.
6) Render will provide a public HTTPS URL such as:
   https://vyapaar-sathi.onrender.com

IMPORTANT:
- The actual public URL is generated by Render after deployment.
- Do NOT put the Gemini API key in index.html.
- Without GEMINI_API_KEY the app can still show the fallback prototype analysis, but arbitrary AI analysis requires the key.
